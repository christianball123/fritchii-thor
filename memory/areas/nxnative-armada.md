- Wants to build a native port of the Switch 2 Ocarina of Time remake that runs on ArmadaOS on the [[ayn-thor]], starting from nxnative (seedds/nxnative)
- Forked it as christianball123/nxnative on GitHub; work is on the linux-arm64 branch
- Has the OoT remake only as a .nup file; has Mario Tennis Fever as an extracted copy (used as the first test game)
- The port is for private use only, never to be shared; had the fork relicensed GPL-3 so GPL code (e.g. NotRexed/Hookshot) can be used in it
